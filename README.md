# Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer, track your score, and enjoy the classic game in your browser.

## Live Demo

[Play Rock Paper Scissors](https://rock-paper-scissor-game-liart-nu.vercel.app/)

## Features

- Play Rock, Paper, or Scissors against the computer.
- Computer randomly selects its move.
- Automatically determines the winner of each round.
- Tracks wins, losses, and ties.
- Saves the score using Local Storage.
- Reset the score at any time.
- Auto Play mode for automatic gameplay.
- Simple and interactive user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Play

1. Open the game using the live demo link.
2. Select Rock, Paper, or Scissors.
3. The computer will randomly select its move.
4. The game displays the result and updates the score.
5. Use the Reset button to clear the score.
6. Use Auto Play to play automatically.

### Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- Choosing the same move results in a tie.
